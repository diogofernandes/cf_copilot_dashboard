# Public GitHub Pages showcase

Verified public URL: https://diogofernandes.github.io/cf_copilot_dashboard/

The public CV edition is a static interactive site under docs/site. GitHub Pages serves the published files from the gh-pages branch in Diogo's personal repository. It needs no Python server or hosting credentials.

Visitors can load all 24 sample invoices, generate a recorded seven-interval forecast, review ten collection priorities, select invoices, generate each recorded collection draft, copy draft text, download the sample or forecast, and explore the project tab.

Results are genuine outputs from the synthetic XGBoost demonstration and local draft policy, generated by scripts/build_showcase.py. The static site clearly labels them as recorded results. Arbitrary uploads and new model inference remain available in the Python application.

## Rebuild

Install requirements_dev.txt, then run:
    python scripts/build_showcase.py

The site files can be served locally with:
    python -m http.server 8510 --directory docs/site

## Publication

Publish only the contents of docs/site to gh-pages. Configure Pages to serve the branch root. No credentials, private data, generated model binaries or backups belong in the publication.

The Python hosting entry point portfolio_app.py remains available as an alternative for a future live-inference deployment.

For subsequent releases, run python scripts/publish_pages.py with GitHub CLI authenticated.
Optional browser verification: install requirements_browser.txt, install Playwright Chromium, then run scripts/verify_showcase.py with SHOWCASE_URL set to the public URL.
